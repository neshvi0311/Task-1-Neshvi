# To-Do List Application

## Overview
This is a simple command-line To-Do List application developed in Python.

## Features
- Add Tasks
- View Tasks
- Mark Tasks as Completed
- User-Friendly Menu

## Technologies Used
- Python

## Concepts Used
- Lists
- Loops
- Conditional Statements
- Dictionaries

## How to Run

1. Download the project
2. Open terminal
3. Run:

python todo.py
