# Expense Tracker

## Overview
A simple Python Expense Tracker that allows users to record expenses and calculate the total amount spent.

## Features
- Add Expenses
- View Expense List
- Calculate Total Spending
- User-Friendly Menu

## Technologies Used
- Python

## Concepts Used
- Lists
- Loops
- Conditional Statements
- Math Operations
- Accumulators

## How to Run

1. Open terminal
2. Navigate to project folder
3. Run:

python expense_tracker.py
