# Random Password Generator

## Overview
A Python-based Random Password Generator that creates strong and secure passwords using letters, numbers, and special characters.

## Features
- User-defined password length
- Random password generation
- Includes letters, numbers, and symbols
- Simple command-line interface

## Technologies Used
- Python

## Concepts Used
- Modules (random, string)
- Loops
- String Manipulation
- User Input Handling

## How to Run

1. Open terminal
2. Navigate to project folder
3. Run:

python password_generator.py
